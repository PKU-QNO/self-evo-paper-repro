## 命名与维护约定（对齐 CLAUDE.md「WORK_LOG 维护规范」）

- **按论文分文件，一篇一文件**：`<NN>-<papername>-v<N>.md`（NN=复现序号，与 case 的 `MMDD-NN-...` 对齐；v<N> 由用户第一句话给定，agent 不自造）。
- **同一篇复现多次 → 分多文件**（`-v1`/`-v2`…），不覆盖旧的。
- **永不归档、永不删减；只增不改历史**。每个会话/报告点结束前向对应文件**追加**带日期条目（详情由 main-agent 在 step11 及各 gate 停机前写，见 CLAUDE.md 规范）。
- 与 `todo.md` 分工：todo = 待进自迭代的临时缓冲（迭代后归档/删减）；WORK_LOG = 永久大框架历史。数据只引用 capsule/run_manifest/.result 路径，不重抄。
- 新建一篇日志：复制 `_TEMPLATE.md` → `<NN>-<papername>-v<N>.md`，填速览 + 首条批次记录；同时在顶层 `../WORK_LOG.md` 摘要表加一行。
