# 蓝图建议：Akimov arXiv 2401.04146 — Fig.3

## 本次是否需要蓝图

**不需要。**

本次复现基于纯 Python 解析计算（numpy + scipy + matplotlib），全部在本地完成，单次求根+出图+对比运行耗时秒级到分钟级，未使用 COMSOL/Magnus，也不涉及 SLURM 作业提交或大规模参数扫描。

## 理由

- Fig.3 复现是完全无量纲化的解析问题（只需 $q_e$、$\varepsilon_i/\varepsilon_e$ 两个标量参数进入），不需要有限元/时域仿真。
- 六面板 loci 求根的计算量（q_e 800 点 × eps 5001 点/切片 × 6 面板）在本地单核可秒级到分钟级完成，无需 128 核/973G RAM 的 HPC 资源。
- 无参数扫描蓝图化的需求——本 case 的"参数"就是论文图的坐标范围本身，已经是穷举网格而非需要扫描优化的物理参数（如波长、半径等蓝图场景）。

## 后续如需扩展

若后续复现 Akimov 论文的 Fig5(c)(f)（$|a_1|,|b_1|$ 材料光谱，需 Ag/Si/SiO2 色散数据）或涉及多层结构/COMSOL 有限元验证的论文，再评估是否需要蓝图化。本 case 不预先设计蓝图占位。
