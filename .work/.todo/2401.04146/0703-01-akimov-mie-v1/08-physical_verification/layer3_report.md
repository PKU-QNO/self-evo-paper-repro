## 一、指标与方法

主指标：**数字化取样点 $p=(q_e,\varepsilon)$ 到同面板同类型复现曲线族的最近归一化距离**

$$ d(p) = \min_{c \in \text{repro}(\text{panel},\text{type})} \sqrt{\left(\frac{q_e^{(p)}-q_e^{(c)}}{10}\right)^2 + \left(\frac{\varepsilon^{(p)}-\varepsilon^{(c)}}{25}\right)^2} $$

- 归一化：$q_e$ 除轴跨度 10，$\varepsilon$ 除轴跨度 25（$[-10,15]$），两轴等权、无量纲、可跨面板聚合。
- 方向：数字化点（带主观误差）→ 复现曲线（密采样真值参照），用 `scipy.spatial.cKDTree` 对归一化 repro 点集建树查询。
- nr 含 `branch_id=0` 平凡线（原图 $\varepsilon=1$ 蓝实线）已纳入。
- 复现点集规模：每面板每类型约 4800–4930 点；数字化点每组 143–179 点，共 1982 点。

**阈值（SEPR 自定，无社区先例）**：归一化距离 中位数 $<0.01$、95 分位 $<0.03$。附加 Gate2 强制判据：曲线支数逐面板一致（T4 已 PASS，本步引用）。

## 三、达标情况（诚实列全）

- **nr（近共振/背景线，含 $\varepsilon=1$ 平凡线）：六面板全部达标。** median 0.0054–0.0074、p95 0.017–0.021、max ≤0.070。这是最强正面证据——复现曲线的 nr 分支位置与数字化基线**逐面板一致**。
- **sr（散射共振线）：median 全部接近或低于 0.01（0.0073–0.0123），但 p95/max 出现长尾。** 5/6 面板 p95 超 0.03（0.052–0.131），仅 TE3 达标（p95 0.021）。TM1/TM2/TM3 median 亦略超（0.011–0.012），确认并细化了 main 先导（见 §五）。
- 全局 verdict：**CONDITIONAL**（median 达标 + 完备性 PASS，但 p95 超阈），交 Gate4 裁决，本步不自行判 FAIL 也不自行放宽。

## 四、长尾成因与不确定度分析

**长尾定位**（`sr_tail_diagnosis.txt`）：sr 的 p95 超阈点（$d>0.03$）占各面板 10–19%（TE3 仅 1.4%），集中在**中大 $q_e$ 区（超阈点 $q_e$ 中位 4–6）**，不是端点效应。

**距离分解**（cKDTree 最近点回查）：sr 超阈点距离由 **$q_e$ 方向主导**（dq_norm 中位 0.03–0.06，对应实际 $dq_e\sim0.3$–$0.6$），$\varepsilon$ 常接近上边界 14.6。这说明超阈点落在**近垂直/陡峭的密集分支段**——曲线在该处 $q_e$ 微变即 $\varepsilon$ 大跨，数字化在此区读数困难，且最近邻度量对沿曲线方向的小偏移被几何放大。

**与数字化不确定度对比**：接口 md 标称数字化不确定度归一化 $\sim0.005$–$0.006$。

- median 层面：全局 0.0074、nr 全部 ≤0.0074、sr median 0.0073–0.0123——与标称不确定度**同量级**（sr 略高 1–2 倍）。**median 尺度上是数字化误差量级，非复现偏差。**
- p95 层面：sr 超阈点偏差 0.03–0.06，超标称 6–12 倍。但成因是**陡峭区度量放大 + 密集分支区数字化固有困难**，而非复现曲线整体错位（若整体错位，nr 也会同步超标，事实 nr 全达标）。

**判断依据（决策问题3）**：证据倾向"**主要是数字化误差 + 度量几何效应，非复现物理偏差**"——理由链：(1) nr 六面板全达标证明曲线位置正确；(2) sr 超阈点由 $q_e$ 方向主导且集中在陡峭段，符合数字化困难特征；(3) 完备性判据 PASS 证明无系统性漏根/多根。但 p95 绝对值确超 SEPR 自定阈值，不能仅凭机理解释就判达标——须 Gate4 裁决。

## 七、Gate4 呈现事项（供 main 呈用户裁决）

**背景**：loci 图（曲线族位置对比）**无文献先例 RMSE/距离阈值**，中位<0.01 / p95<0.03 为 SEPR 本 case 自定，量级取"数字化误差 + 轴范围百分比"。

**现状**：全局 median 达标、nr 全达标、完备性 PASS；唯一未过项是 **sr 的 p95 长尾**（全局 p95 0.0426 vs 阈值 0.03，5/6 面板 sr p95 超标）。

**给用户的选项（不自行选择，交 Gate4）**：
1. **接受为数字化误差 + 度量几何效应**：认可 nr 全达标 + median 达标 + 完备性 PASS 已充分佐证复现正确，sr p95 长尾归因陡峭区数字化困难 → 判 Layer3 通过（`partial_physical_match`）。
2. **微调 p95 阈值**：将 p95 阈值放宽到覆盖 sr 陡峭区（如 0.05–0.06），需用户认可"loci 陡峭段容忍更大 p95"的物理合理性 → 但需用户明确批准，本步不自行放宽。
3. **sr 陡峭区加密数字化重测**：对中大 $q_e$ 密集分支区加密采样重新数字化，降低度量放大效应后重算 p95 → 工作量较大，回到 step07 数字化环节。

**建议倾向（仅建议，非裁决）**：证据支持选项 1（median 达标 + nr 全达标 + 完备性 PASS 三重佐证复现正确，p95 长尾有明确机理解释），但因阈值 SEPR 自定且 p95 客观超标，**必须由用户在 Gate4 拍板**。
