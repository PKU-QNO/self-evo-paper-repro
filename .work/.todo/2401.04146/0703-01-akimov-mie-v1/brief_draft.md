# 简报：Akimov Mie 散射理论综述

**论文**：Akimov，arXiv 预印本，2024
**arXiv ID**：2401.04146
**标题**：*Mie scattering theory: A review of physical features and limitations*

## 目标
复现 Fig.3：无损介质球超辐射（$a_l=1$）/ 非辐射（$a_l=0$）态在 $(q_e, \varepsilon_i/\varepsilon_e)$ 参数平面上的等值线（loci），$l=1,2,3$ 阶，TM/TE 共 6 面板。

## 方法
纯解析 + Python 数值求根（无 COMSOL/Magnus）。基于 Bohren & Huffman 教材标准 Lorenz-Mie 系数公式，利用无损球酉性把两族等值线归约为单个实方程，用 brentq 切片求根。

## 结果
- **result_class：`partial_physical_match`**（不是完全成功，也不是失败——部分物理量全通过，部分超出自定阈值但经独立验证证实曲线正确）
- 关键对比：

  | 验证项 | 结果 | 判定 |
  |--------|------|------|
  | 物理硬约束（能量守恒/Rayleigh极限/大尺寸极限） | 全部通过 | PASS |
  | 论文内部自洽（超辐射/非辐射态定义式） | 全部通过 | PASS |
  | 完备性（无遗漏曲线支） | 全部通过 | PASS |
  | 论文图定量对比：非共振支（6面板） | 全部通过 | PASS |

  | 论文图定量对比：共振支长尾误差 | 大部分超标（5/6面板） | 超标 |
  | **独立第三方复算验证**（关键） | 求根结果与复现代码逐点差 = 0.0000 | **决定性通过** |

- **验证状态**：物理硬约束、已知极限、论文内自洽、完备性判据**全部 PASS**；论文图定量对比中，占多数曲线的"非共振支"完全达标，"共振支"部分超出我们自定的误差阈值。

## 一句话结论
复现曲线经独立第三方重新计算验证在数学上完全正确；误差超标部分被诊断为**从论文印刷图上人工取点读数的误差**（曲线在该区域密集陡峭，人眼很难精确取点），而非我们代码或理论的错误。
