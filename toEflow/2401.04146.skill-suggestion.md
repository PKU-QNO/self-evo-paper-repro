### 建议 2：Layer3 阈值缺乏几何敏感度校正——loci 图对比方法论待补

**tier**：P1（值得修，main-agent 确认）
**影响 skill**：`optics-mie-reproduction/references/verification.md` 或新增 `references/layer3_loci_comparison.md`
**适用边界**：
- applies_when：论文图是"等值线/loci 曲线族"而非"数据点曲线"（如本次 Fig3），且曲线在某些区域近乎垂直/陡峭
- does_not_apply_when：论文图是离散数据点对比（如光谱曲线），最近距离度量无此问题

**原文不足**：
```
当前 verification.md 的 Layer3 判据只给"归一化最近距离 median/p95 阈值"，
未讨论"当曲线陡峭时，最近距离度量对沿曲线方向的小偏移会被几何放大"这一效应。
```

**改进建议**：
```
补充一节"loci/等值线类图的度量陷阱"：当目标曲线在参数空间中局部接近垂直（一个轴的
微小变化对应另一轴的大幅跳变）时，欧氏距离（即使归一化）对该方向的数字化误差会被放大，
不能只用全局阈值卡；建议对陡峭区域提供"沿曲线切向 vs 法向分解距离"的可选度量，
或至少在报告模板中要求做"长尾定位+距离分解"诊断（本 case 的 sr_tail_diagnosis.txt
就是这个诊断，但目前是 sub-agent 临时想到做的，未固化进 skill 流程）。
```

**本次 case 实例**：
```
Fig3 的 sr（共振支）在正大 ε + 中大 q_e 区域呈密集陡峭分支，5/6 面板 p95 超标
(0.052-0.131)，但 nr（非共振支，曲线平缓）六面板全部达标。
distance分解显示超阈点由 q_e 方向主导(dq_norm中位0.03-0.06)——这正是"陡峭曲线+
最近距离度量"的几何放大效应，而非复现偏差（已用独立求根Δ=0.0000证实）。
```

### 建议 3：Gate4-类"CONDITIONAL"结果缺乏标准化的独立复算验证协议

**tier**：P1（值得修，main-agent 确认）
**影响 skill**：`main-agent/workflow/08-result_analysis/SKILL.md` 或 `workflow/11-main_agent_report/SKILL.md`
**适用边界**：
- applies_when：Layer3 量化对比出现"部分达标部分超标"的 CONDITIONAL 结果，需要 human gate 裁决是否接受
- does_not_apply_when：Layer3 全部 PASS 或全部 FAIL 时不需要此额外验证（结论已明确）

**原文不足**：
```
当前 workflow 在 Layer3 CONDITIONAL 时只给"呈现给用户3个选项"的流程，未固化
"用独立于被测代码路径的第二实现重新计算关键结果，做数学正确性的决定性验证"
这一做法——本次是 optics_agent CC 临时想到并执行的，不是 skill 里写好的标准步骤。
```

**改进建议**：
```
在 step08/step09 补一条标准动作："当 Layer3 出现 CONDITIONAL 或超标结果时，
若怀疑误差来源是'数字化/读图 vs 复现代码错误'的二义性，应做一次独立复算验证——
用已通过 Gate 验证的底层核（如本 case 的 scattering.py）、完全绕开被测的上层脚本
（如本 case 的 fig3_loci.py），独立重新计算目标量，与被测脚本产物逐点比对。
若 Δ≈0，则可决定性地把归因锁定为'非代码错误'，大幅提高 Gate 裁决置信度。"
这本质是"用同一个已验证的核心，走两条独立的上层路径互证"，类似 T2 交叉验证的思路，
但用在 Layer3 而非 Layer1。
```

**本次 case 实例**：
```
GATE4-决定.md 的核心裁决依据就是这个独立复算（Δ=0.0000），比"看误差机理讲得通不通"
的定性论证强得多。这个技巧值得固化为可复用步骤，而不是只在本 case 里出现一次。
```
