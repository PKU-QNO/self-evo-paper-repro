为什么慢

慢不是因为只画了几张图，而是先把“不能自欺”的基础设施搭起来

V1 / V2 / V3 演进

  • V1：可自迭代 DSL，自由度太高，风险包括拓扑漂移、reward hacking、记忆污染。
  • V2：固定拓扑 runner，更安全，但工程成本偏高，真实复现尚未跑通。
  • V3：Claude 三层子 agent + 人工 gate + deterministic verifier，是当前方案。

实际阻力

  • Claude 中转站和工具链不稳定，长上下文下 tool-call 失败需要熔断。
  • 子 agent 自称完成不等于磁盘产物完整，需要逐项核验。
  • 每篇论文都要人工判断“物理上是不是真的复现”。
  • 个人原因会上口述，文档不展开。
