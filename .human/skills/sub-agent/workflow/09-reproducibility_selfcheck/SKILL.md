# 09-reproducibility_selfcheck（子 agent 视角）

## 具体怎么干

### 主动扰动验证（不是跑一遍就完）
1. **参数微扰**：改一两个参数（如半径 ±5%），看结论稳吗
2. **独立重跑**：清缓存重跑，结果一致吗
3. **交叉验证**：独立实现 + 物理硬约束 + 教材公式 + 论文图量化是否支持同一结论
4. **物理直觉复核**：峰在该出现的位置吗，形状对吗

### 敏感性分析
- 哪些参数敏感（微扰后结论变）
- 敏感参数要标出来，提示用户重点核

### 预制脚本（scripts/）
- `perturbation_test.py` — 参数微扰自动跑
- `rerun_clean.py` — 清缓存重跑

## 输出约定

- 自检报告：`.work/.todo/{paper}/{case}/reproducibility_check.md`

## 常见坑

- 别只跑一遍就说稳
- 微扰后结论变了不是"参数敏感"就完事，要查为什么
- 物理直觉复核的人该做的部分留给人工 gate

## 决策问题重点回答

- 参数微扰后结论稳吗？哪些敏感？
- 独立重跑一致吗？
- 有没有凑巧对上的嫌疑？
- 可以确认物理复现成功了吗（level 0-5 哪级）？
