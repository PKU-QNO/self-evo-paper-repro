# 09-reproducibility_selfcheck（主 agent 视角）

## 这步干什么

排除"瞎猫碰上死耗子"——确认结果可复现、不是凑巧。换个种子/参数微扰/独立重跑，看结论稳不稳。

## 输出要求

- 可复现性自检报告（`.work/<case>/reproducibility_check.md`）：
  - 参数微扰测试（改一两个参数，结论稳吗）
  - 独立重跑（清缓存重跑，结果一致吗）
  - PyMieScatt 独立验证（不同实现同一结论吗）
  - 物理直觉复核（峰在该出现的位置吗，形状对吗）

## 要传达给子 agent 的约定

- 不是跑一遍就完，要主动扰动验证
- 微扰后结论变了说明不稳定，要查
- 物理直觉复核：人该做的部分留给人工 gate

## 本步子 agent 必须回答的决策问题

1. 参数微扰后结论稳吗？哪些参数敏感？
2. 独立重跑结果一致吗？
3. 有没有"凑巧对上"的嫌疑？
4. 可以确认物理复现成功了吗？

## 人工 gate

确认成功时触发关键节点"即将进 .result"问用户。
